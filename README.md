# Pharos Academy — website

Replacement for the current Wix site at <https://www.pharosacademy.net/>.

Pharos Academy is a Christian classical hybrid microschool in Enola, PA, operating on the
H.O.P.E. model (Helping Our Parents Educate).

**Status:** repo created, not yet scaffolded. Scoping decisions are recorded in issue #1.

## Planned stack

Astro 6 + Tailwind 4 on Vercel, static by default with SSR on the inquiry endpoint and
`/admin`. Neon + Drizzle for lead storage, Resend for notification email. vitest +
Playwright.
